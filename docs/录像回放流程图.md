## 2. 管理端时序

```mermaid
sequenceDiagram
  autonumber
  actor U as 用户
  participant DV as DevicesView
  participant Panel as RecordingPlaybackPanel
  participant TL as RecordingDayTimeline
  participant API as RecordFileController
  participant Svc as RecordFileService
  participant Disk as 录像目录
  participant Vid as video标签

  U->>DV: 点击「录像回放」
  DV->>Panel: 打开弹层 deviceId
  Panel->>TL: 挂载（默认 fetch + token URL）
  TL->>API: GET /api/recordings?deviceId&from&to<br/>Authorization Bearer
  API->>Svc: list(deviceId, from, to)
  Svc->>Disk: 扫描 *.mp4 过滤时间
  Disk-->>Svc: 文件列表
  Svc-->>API: 元数据（无 videoUrl）
  API-->>TL: {code:0, data:[...]}
  TL->>TL: buildDaySegments（绿/灰）

  alt 当天无录像
    TL-->>U: 提示空日，播放锁定
  else 有绿段
    U->>TL: 点播放 / 拖绿段
    TL->>TL: hitSegment? pickRecordAt
    TL->>Vid: loadAndPlayOne(url?token=)
    Vid->>API: GET /api/recordings/{id}/{file}?token=
    Note over API: AuthInterceptor 认 Header 或 Query token
    API->>Svc: openFile
    Svc->>Disk: 安全打开
    Disk-->>Vid: video/mp4
    Vid-->>U: 播放
    Vid->>TL: ended → 下一段（不预取）
  end
```

## 3. 业务端时序（含停用拦截）

```mermaid
sequenceDiagram
  autonumber
  actor U as 用户
  participant Biz as BizPortalView
  participant Panel as RecordingPlaybackPanel
  participant API as BizPortalController
  participant Svc as RecordFileService
  participant Open as OpenApi 文件路径
  participant Vid as video标签

  U->>Biz: 选择设备
  Biz->>API: GET /api/biz/devices/{deviceId}
  API-->>Biz: playable / livePlayable / liveStream

  alt status=已停用
    Biz-->>U: 「录像回放」禁用
  else 可回放
    U->>Biz: 点击录像回放
    Biz->>Panel: 覆盖 fetch→biz列表<br/>getVideoUrl→record.videoUrl
    Panel->>API: GET /api/biz/devices/{id}/recordings?from&to
    alt 服务端再次发现停用
      API-->>Panel: 失败 message=设备已停用
    else OK
      API->>Svc: listWithVideoUrls
      Svc-->>API: 含 videoUrl=/api/open/recordings/...
      API-->>Panel: data[]
      U->>Panel: 点绿段播放
      Panel->>Vid: src=videoUrl（无 token）
      Vid->>Open: GET /api/open/recordings/{id}/{file}
      Open-->>Vid: MP4（免鉴权）
    end
  end
```

## 5. 按需播放决策（前端核心）

```mermaid
flowchart TD
  Start[用户 seek / 点播放] --> Hit{命中绿段 hitSegment?}
  Hit -->|否 灰区| Ignore[忽略 · pointer-events 锁死]
  Hit -->|是| Pick[pickRecordAt 选文件]
  Pick --> Same{与当前 src 同文件?}
  Same -->|是| Seek[只改 currentTime]
  Same -->|否| Unload[unloadVideo 清 src]
  Unload --> Load[loadAndPlayOne<br/>preload=none]
  Load --> HTTP[浏览器 GET 文件 URL]
  HTTP --> Play[播放]
  Play --> Ended{ended?}
  Ended -->|有下一段| Pick
  Ended -->|无| Stop[停止]
```

## 6. 时间轴交互（不打列表接口）

```mermaid
flowchart TB
  Bar[DayTimelineBar]
  Bar --> W[滚轮 → zoomAt]
  Bar --> Box[框选 → zoomToRange]
  Bar --> Pan[Alt/Shift 拖 → panView]
  Bar --> Full[双击/全天/Esc → 0~86400]
  Bar --> Green[绿段拖/点 → emit seek]
  Bar --> Grey[灰底 → 不可播仅可框选/平移]
  Green --> PlayAt[playAt]
```

**会打列表的时机：** 打开面板、换日期、点刷新。  
**会打文件的时机：** 换到新 MP4 播放。同文件 scrub 不发新请求。

---

## 7. 鉴权矩阵

| 接口 | 鉴权 | 播放侧用法 |
|------|------|------------|
| `GET /api/recordings` | Bearer | 管理端列表 |
| `GET /api/recordings/{id}/{file}` | Bearer 或 `?token=` | 管理端 `<video>` |
| `GET /api/biz/.../recordings` | Bearer | 业务端列表 |
| `GET /api/open/.../recordings` | 无 | 第三方列表 |
| `GET /api/open/recordings/{id}/{file}` | 无 | 业务/开放播放字节 |

---

## 8. 落盘与列表字段

```
{output-dir}/
  {deviceId}/
    20260915_143000.mp4   ← 文件名=段开始时间
```

列表项：`deviceId, fileName, timestamp, recordTime, size, path`；`listWithVideoUrls` 额外 `videoUrl`。  
无结束时间时前端用 `clipSeconds`（默认 300）推绿段终点。
